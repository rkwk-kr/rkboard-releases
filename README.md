# RK Board 설치 파일

이미지·영상·음원을 노드 보드로 펼쳐 보고 메모하는 데스크톱 앱 **RK Board**의 설치 파일만 올려 두는 곳이에요.

- 받기: [Releases](../../releases/latest)에서
  - Mac (Apple 칩): `.dmg`
  - Windows: `-setup.exe`
- 0.6.2부터는 앱 안에서 새 버전을 확인하고 업데이트할 수 있어요.
- 코드 서명이 없어서 처음 열 때 경고가 뜰 수 있어요.
  - Mac에서 "손상되었다"고 나오면 터미널에서: `xattr -dr com.apple.quarantine "/Applications/RK Board.app"`
  - Windows에서 "PC 보호" 창이 나오면: 추가 정보 → 실행
